# Atividade Pilha e Fila

**Aluno:** Wanderley Silva

## Descrição
Projeto em Java que implementa as estruturas de dados Pilha (LIFO) e Fila (FIFO) utilizando arrays, sem uso de estruturas prontas.

## Conceitos

### Pilha (LIFO)
Último a entrar, primeiro a sair.

### Fila (FIFO)
Primeiro a entrar, primeiro a sair.

## Como executar
1. Abrir no IntelliJ IDEA
2. Executar a classe Main.java

## Funcionalidades
- Pilha: push, pop, peek, isEmpty, isFull, display
- Fila: enqueue, dequeue, front, isEmpty, isFull, display
